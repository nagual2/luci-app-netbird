# Политика безопасности luci-app-netbird

**Языки:** [English](SECURITY.md) | **Русский** (эта страница) | [Deutsch](SECURITY.de.md)

## Сообщение об уязвимостях

Если вы нашли уязвимость в этом репозитории, пожалуйста, **не создавайте публичный issue**. Вместо этого:

1. Используйте [приватные security-адвайзори GitHub](https://github.com/nagual2/luci-app-netbird/security/advisories/new)
2. Подробно опишите уязвимость
3. Приложите шаги воспроизведения (если применимо)
4. Дайте 90 дней на исправление до публичного раскрытия

Уязвимости самого NetBird сообщайте в апстрим: https://github.com/netbirdio/netbird/security

## Целостность пакетов

Готовые `apk` собираются GitHub Actions из исходников этого репозитория. Перед установкой проверяйте:

```sh
# контрольная сумма публикуется вместе с каждым релизом
sha256sum netbird-0.77.1-r1_x86_64.apk

# содержимое пакета
apk manifest /tmp/netbird.apk        # на роутере
```

Пакеты не подписаны (нужен `--allow-untrusted`), так как нет ключа подписи фида; устанавливайте их только из доверенных источников — напрямую из Releases этого репозитория.

## Замечания по безопасности для пользователей

- Демон работает от root и открывает локальный IPC-сокет. Версии NetBird < 0.76.0 уязвимы к локальной эскалации привилегий ([GHSA-qcpp-8vwj-hhwr](https://github.com/netbirdio/netbird/security/advisories/GHSA-qcpp-8vwj-hhwr)) — держите пакет обновлённым.
- Init-скрипт OpenWrt задаёт `NB_DISABLE_SSH_CONFIG=1` — это запрещает клиентам NetBird включать SSH-сервер на роутере через mesh. Не убирайте эту защиту, если не понимаете последствий.

## Практики безопасности для контрибьюторов

### Предотвращение утечки секретов

```bash
# Проверка staged-изменений на секреты
git diff --cached | grep -iE "password|token|api.?key|secret|credential"

# Или через gitleaks (если установлен)
gitleaks detect --staged
```

Не встраивайте токены в git URL, скрипты или логи CI. Учётные данные роутеров — в `~/.ssh/config`, но не в этом репозитории.

### Чеклист перед PR

- [ ] Нет паролей и токенов
- [ ] Нет хостнеймов и IP-адресов роутеров
- [ ] Изменения не ослабляют защиту init-скрипта (env-флаги выше)
- [ ] `PKG_HASH` в Makefile соответствует апстримному тарболлу

## Настройки безопасности GitHub

1. **Dependabot:** следит за версиями GitHub Actions (`.github/dependabot.yml`)
2. **Secret scanning:** рекомендуется включить в настройках репозитория
3. **Branch protection:** рекомендуется для `main`

## Зависимости

Сборочный пайплайн использует только официальный тарболл OpenWrt SDK с downloads.openwrt.org и стандартные инструменты сборки. Сторонние зависимости этот репозиторий не добавляет.
